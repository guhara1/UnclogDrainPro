# 흐름터 — 전국 누수탐지·누수공사·하수구막힘·배관막힘 안내

정적 사이트입니다. `public/` 안이 그대로 올라갑니다.

## 구성
| 자리 | 쪽수 |
|---|---|
| 홈·서비스·고정 쪽 | 17 |
| 지역(시도 / 시군구 / 행정동) | 1,038 |
| 시공점 | 2,306 |

- 지역은 **전국 3층**입니다. 시도 → 시·군·구 → 행정동 순으로 한 단계씩 좁힙니다.
- 행정동은 구마다 대표 3곳입니다. `역삼1동·2동` 같은 숫자 행정동은 **대표 한 곳으로 합쳤습니다.**
- 업체는 **가상**입니다. 접수는 대표 전화 한 곳으로 받습니다.
- 히어로와 시공점 그림은 **글자 + 선으로 그린 SVG** 입니다. 사진은 실제 작업 사진만 씁니다.

## 고치는 자리
| 무엇 | 어디 |
|---|---|
| 상호·전화·도메인·배색 | `gen/cfg.py` |
| 지역 데이터 | `gen/regions.py` → `regions.json` |
| 지역 글 | `gen/prose.py` |
| 서비스 글 | `gen/prose_svc.py` |
| 제목·디스크립션 | `gen/seo.py` |
| 화면·CSS | `gen/tpl.py`, `gen/svg.py` |

굽기: `python3 gen/build.py` · 점검: `python3 gen/check.py`

> 도메인을 사면 `gen/cfg.py` 의 `HOST` 한 줄만 고치고 다시 구우면 됩니다.
> canonical·사이트맵·RSS·스키마가 모두 따라옵니다.
